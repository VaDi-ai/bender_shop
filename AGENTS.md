# Правила работы с репозиторием

Перед началом и перед завершением любой задачи прочитай [политику порядка](docs/REPOSITORY-HYGIENE.md).

Обязательные правила:

1. В репозитории оставляем только исходники, конфигурацию, документацию, тесты, воспроизводимые скрипты и осмысленные доказательства/снапшоты.
2. Фото, выгрузки Sheets, CSV/XLSX, ZIP, логи, скриншоты QA, локальные дампы, секреты, `dist/`, `generated/`, `node_modules/` и временные файлы не коммитим.
3. Временные результаты сразу складываем вне репозитория в карантин вида `repo-cleanup-quarantine-YYYY-MM-DD`; не удаляем материал без необходимости и проверки.
4. После работы очищаем временные результаты и запускаем `npm run check:hygiene`.
5. Добавляем файлы в Git явно, через `git add <файлы>`; `git add -A` не используем.
6. Если появляется новый класс локальных артефактов, сначала добавляем его в `.gitignore` и эту политику.

Источник истины: [docs/REPOSITORY-HYGIENE.md](docs/REPOSITORY-HYGIENE.md).
