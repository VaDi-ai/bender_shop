Принципы, зашитые в мокап:
• кнопка = глагол + объект («Разобрать прайс», «Применить цены», «Заменить фото»), раздел = существительное;
• под каждой кнопкой — что произойдёт дальше и можно ли откатить;
• статус всегда виден: включён / выключен / черновик / не разобран / нужна помощь;
• пустое состояние = не «нет данных», а приглашение к действию;
• опасное — отдельной зоной, красным, с описанием последствий;
• флагман «Цены» — вторая вкладка: разобрать → проверить → применить, плюс очередь «не узнал» с обучением в один тап;
• самообучение: связал название один раз → система запомнила, дальше сама.
